# LOW/HIGH FIDELITY PROTOTYPE


## Assigment
Utilizing Figma or similar tool, design either a low or high-fidelity prototype for the landing/home page of your web application. Do make use of ChatGPT for your project to speed this task up. Provide it with some context: personas, sitemap, description, developed in the previous assignments. Then ask ChatGPT to propose design requirements and content outline for your page.
Apply fundamental design principles, including consistency, readability, and visual hierarchy, to create an aesthetically pleasing and user-friendly interface. In particular, try to apply CRAP principles for visual design.

## Design requirements
The homepage must:

1. Introduce the brand clearly and instantly
2. Highlight product offerings in a compelling way
3. Guide users toward conversion (e.g., Shop, Learn More, Order Now)
4. Build trust with users through visuals & messaging
5. Be responsive and accessible on all screens (desktop, tablet, mobile)

## Key User Scenarios
Users visiting the homepage should be able to:

1. Identify what the site sells within 3 seconds
2. Navigate to product categories
3. Learn production values and benefits
4. Access ordering or shopping functionality
5. Contact the business or find social proof

## Functional Requirements

The homepage must include:
1. Navigation Bar
- Logo
- Menu links (Home, Products, About, Contact)
- Primary call-to-action (Shop / Order Now)

2. Hero Section
- Large visual background (photo of olive oil or grove)
- Headline & subheadline
- Primary CTA button

3. Benefits / Value Props
- Icons or visuals
- Short explanatory texts

4. Featured Products Preview
- 2–4 product items
- Images, names, prices, CTA buttons

5. Trust Section
- Testimonials, ratings, or awards

6. Footer
- Contact information
- Social media links
- Legal links (Privacy, Terms)

## Content Requirements
1. Hero Section
- Headline (e.g., “Pravo domaće maslinovo ulje”)
- Subheadline (one sentence)
- Primary CTA: Order Now

2. Benefits Block
- 3–4 Benefit points
- Short, clear text per item

3. Product Cards
- Product image
- Product title
- Price
- CTA

## Interaction & UX Requirements
- Responsive design with mobile-friendly breakpoints (desktop/tablet/mobile) 
- Hover states on buttons and links
- Clear visual hierarchy of elements
- Progressions that invite users to scroll

## Accessibility Requirements
To ensure inclusive design:
- Alt text for all images
- Semantic structure (headlines, nav, footer)
- Sufficient contrast (text/background)

## Branding & Visual Requirements
- Color scheme should reflect olive tones and natural palette
- Typography hierarchy (e.g., H1 for headlines, H2 for section titles)
- Consistent spacing and alignment
- Use of brand logo, icons, and product photography

## Performance Considerations
- Use optimized images
- Keep page load fast
- All elements should support smooth scroll and rendering
